# TechGear - Sistema Híbrido de Catálogo y Pedidos

Sistema web híbrido desarrollado con FastAPI, Django y MongoDB Atlas.

## Arquitectura

El proyecto está dividido en dos componentes principales:

- `techgear_api`: API REST desarrollada con FastAPI.
- `techgear_web`: aplicación web desarrollada con Django.

## Tecnologías

- Python
- FastAPI
- Pydantic
- Motor
- MongoDB Atlas
- Django
- Uvicorn

## Requisitos

- Python 3.12
- MongoDB Atlas
- Entorno virtual de Python
